About Me

I'm Mahmoud Mohamed, a versatile technologist who works across four different worlds: building the web, defending it, designing for it, and automating it with AI.

I started with web development, learning how to turn ideas into fast, responsive websites using modern tools and clean code.

My goal is simple: keep learning new skills and use them to build things that are useful, secure, and good-looking.
